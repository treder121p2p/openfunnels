# Funnel Hackers Cookbook — Полная карта туннелей

**Источник:** The Funnel Hackers Cookbook, Chapter 3 (стр. 229-305)
**Ключевой принцип:** Туннель = набор из 2-4+ страниц, соединённых автоматическими сериями сообщений (email/SMS)

---

## Ключевые понятия

### Страница (Page)
Один экран лендинга с конкретной целью:
- **Opt-in страница** — собирает email (Squeeze, Lead Magnet, Reverse Squeeze)
- **Продающая страница** — продаёт продукт (Sales Letter, VSL, Order Form)
- **Thank You страница** — подтверждает действие + ведёт дальше
- **Bridge страница** — связывает два концепта / pre-sell
- **Registration страница** — регистрация на мероприятие
- **Confirmation страница** — подтверждение регистрации
- **Replay страница** — повтор показа вебинара/мероприятия
- **OTO (One-Time Offer)** — единственный оффер после покупки
- **Downsell** — пониженная цена после отказа от OTO
- **Offer Wall** — стена с дополнительными офферами

### Автоматическая серия (Follow-Up Sequence)
После opt-in (сбора email) запускается серия писем:
- **Day 0:** Благодарность + обещанный контент
- **Day 1-3:** Напоминание + ценность
- **Day 5-7:** Soft-sell / приглашение на следующий этап
- **Day 14+:** Retargeting / жёсткая продажа

### Воронка (Funnel)
Комбинация 2-4+ страниц + автоматические серии, ведущая к конкретному результату:
- Lead → сбор контактов
- Sale → получение оплаты
- Event → проведение мероприятия
- Retention → удержание клиента

## 4 категории туннелей

### 1. LEAD FUNNELS (Захват лидов) — 7 шт.

**Цель:** Собрать email/контакты потенциальных клиентов

| # | Название | Страниц | Структура туннеля |
|---|----------|---------|-------------------|
| 1 | **Squeeze Page Funnel** | 2 | `Squeeze Page` → `Thank You Page` |
| 2 | **Reverse Squeeze Page Funnel** | 2 | `Reverse Squeeze Page` → `Thank You Page` |
| 3 | **Lead Magnet Funnel** | 2 | `Lead Magnet Page` → `Thank You Page` |
| 4 | **Bridge Funnel** | 2 | `Squeeze Page` → `Bridge Page` |
| 5 | **Survey Funnel** | 1 | `Survey Page` → (разветвление по ответам) |
| 6 | **Application Funnel** | 3 | `Reverse Squeeze Page` → `Application Page` → `Thank You Page` |
| 7 | **Ask Campaign Funnel** | 2 | `Ask Page` → `Thank You Page` |

#### Детали по страницам:

**Squeeze Page (Страница захвата):**
- Цель: создать любопытство → email
- Элементы: заголовок-крючок + подзаголовок + форма
- CTA: "Получить доступ" / "Скачать бесплатно"

**Reverse Squeeze Page:**
- Цель: сначала дать ценность (видео), потом попросить email
- Элементы: видео + текст + форма после просмотра
- Качество лидов выше, конверсия ниже

**Lead Magnet Page:**
- Цель: обменять конкретный подарок (ebook, видео, купон) на email
- Элементы: описание магнита + benefits + форма
- Работает лучше всего для холодной аудитории

**Bridge Page:**
- Цель: связать два концепта / pre-sell перед продажей
- Элементы: история + видео + CTA на следующий шаг
- Ключевой для аффилиатов и network marketing

**Survey Page:**
- Цель: опрос → сегментация → перенаправление на нужный флоу
- Элементы: вопросы + progress bar + ветвление
- Позволяет показывать разные офферы разным сегментам

**Application Page:**
- Цель: квалификация клиентов для high-ticket
- Элементы: benefits + application form + "apply now"
- Используется для коучинга/консалтинга

**Ask Page:**
- Цель: узнать что хочет аудитория
- Элементы: вопрос + открытые ответы + CTA
- Создаёт продукт на основе реальных запросов

---

### 2. BUYER FUNNELS (Продажи) — 5 шт.

**Цель:** Получить оплату + увеличить средний чек

| # | Название | Страниц | Структура туннеля |
|---|----------|---------|-------------------|
| 1 | **2-Step Tripwire Funnel** | 4 | `Two Step Order Page` → `OTO Page` → `Downsale Page` → `Offer Wall` |
| 2 | **Video Sales Letter (VSL) Funnel** | 4 | `VSL + Order` → `OTO` → `Downsell` → `Offer Wall` |
| 3 | **Sales Letter Funnel** | 4 | `Sales Letter Order Form` → `OTO Page` → `Downsell` → `Offer Wall` |
| 4 | **Membership Funnel** | 4 | `VSL + Order` → `Offer Wall` → `Membership Access` → `Membership Page` |
| 5 | **Daily Deal Funnel** | 2 | `Two Step Order Form` → `Share Page` |

#### Детали по страницам:

**Order Form (Форма заказа):**
- Цель: получить платёж
- Элементы: описание продукта + цена + форма оплаты + guarantee

**OTO Page (One-Time Offer):**
- Цель: дожать upsell сразу после покупки
- Элементы: "Ещё один продукт со скидкой" + "Да, добавить!" / "Нет, спасибо"
- Работает потому что клиент уже "в热 Mode"

**Downsell (Даунсейл):**
- Цель: предложить пониженную цену если отказались от OTO
- Элементы: та же ценность, но дешевле / рассрочка
- Спасает 15-25% отказавшихся

**Offer Wall (Стена офферов):**
- Цель: показать все доступные продукты
- Элементы: список продуктов с ценами и CTA

**Share Page:**
- Цель: вирусное распространение (реферальная программа)
- Элементы: "Поделись с другом — получи скидку"

---

### 3. EVENT FUNNELS (Мероприятия) — 4 шт.

**Цель:** Провести мероприятие + продать на нём

| # | Название | Страниц | Структура туннеля |
|---|----------|---------|-------------------|
| 1 | **Invisible Funnel** | 3 | `VSL + Order` → `OTO` → `Offer Wall` |
| 2 | **Webinar Funnel** | 4 | `Webinar Registration` → `Confirmation` → `Indoctrination` → `Replay` |
| 3 | **AutoWebinar Funnel** | 5 | `Registration` → `Confirmation` → `Broadcast` → `Replay` → `Indoctrination` |
| 4 | **Product Launch Funnel** | 4 | `Product Launch` → `Sales Page X3` → `Product Launch + Order` |

#### Детали по страницам:

**Webinar Registration:**
- Цель: регистрация на вебинар
- Элементы: дата/время + спикер + benefits + форма

**Confirmation Page:**
- Цель: подтвердить + начать серию indoctrination
- Элементы: "Вы зарегистрированы!" + "Добавьте в календарь" + первое письмо

**Indoctrination Page:**
- Цель: подготовить аудиторию к вебинару
- Элементы: история спикера + что узнаете + social proof

**Broadcast Page:**
- Цель: показать вебинар (живой или записанный)
- Элементы: видео-плеер + кнопка "Купить"

**Replay Page:**
- Цель: повтор для тех кто не успел
- Элементы: видео + таймер дедлайна + CTA

**Product Launch Pages (3 предзапуска):**
- Цель: создать предвкушение перед запуском
- Каждая страница = отдельное видео/контент
- Карты открываются на ограниченное время

## 6 категорий бизнеса и рекомендации

| Категория | Описание | Лучшие туннели |
|-----------|----------|----------------|
| **Authors/Coaches/Consultants** | Инфопродукты, книги, коучинг | Lead Magnet → Webinar → Application |
| **Professional Services** | Врачи, риэлторы, бухгалтеры | Bridge → Application → Sales Letter |
| **Retail** | Рестораны, фитнес, салоны | Coupon → Daily Deal → Storefront |
| **Ecommerce** | Физические товары (Amazon, Shopify) | Storefront → Product Launch → Sales Letter |
| **Network/Affiliate** | Дистрибьюторы, аффилиаты | Bridge → Webinar → Application |
| **B2B** | Продажи бизнесу | Application → Sales Letter → Webinar |

## Маппинг на OpenFunnels

### Типы страниц → Блоки

| Страница | Layout | Блоки |
|----------|--------|-------|
| Squeeze Page | `two-column-66-33` | text (headline) + form |
| Reverse Squeeze | `single` → `two-column` | video + text → form |
| Lead Magnet | `two-column` | text (benefits) + form |
| Thank You | `single` | text (подтверждение) + button (next step) |
| Bridge Page | `two-column` | video + text (pre-sell) |
| Sales Letter | `single` | text (длинное письмо) + button (buy) |
| Order Form | `single` | form (payment) + text (гарантия) |
| Webinar Registration | `two-column` | text (дата/спикер) + form |
| Confirmation | `single` | text (подтверждение) + button (calendar) |
| Replay | `single` | video + countdown + button (buy) |
| OTO | `single` | text (оффер) + button (yes/no) |
| Application | `two-column` | text (benefits) + form (apply) |

### Автоматические серии (post-opt-in)

| После страницы | Серия писем | Цель |
|----------------|-------------|------|
| Squeeze/Lead Magnet | Welcome → Value → Soft sell → Hard sell | Прогреть → Продать |
| Webinar Reg | Reminder Day -1 → Reminder Day 0 → Replay | Доходить до вебинара |
| Order Form | Thank you → Upsell → Cross-sell | Увеличить LTV |
| Application | Qualification → Call booking → Follow-up | Закрыть high-ticket |

## Итого: 22 туннеля = комбинации страниц

**Принцип:** Берёте страницы как "ингредиенты" и собираете "торт" (туннель) по рецепту.

**Примеры:**
- Lead Magnet Funnel = Lead Magnet Page + Thank You Page + Email Series
- Webinar Funnel = Registration + Confirmation + Indoctrination + Replay + Email Series
- Sales Letter Funnel = Sales Letter + Order Form + OTO + Downsell + Offer Wall + Email Series
