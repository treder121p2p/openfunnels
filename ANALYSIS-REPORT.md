## ЧАСТЬ 2: Созданные шаблоны для OpenFunnels

### Шаблон 1: Squeeze Page Funnel
- **Файл:** `docker/openfunnels/mcp/templates/squeeze-page-funnel.openfunnels.json`
- **Категория:** Lead
- **Секции:** 3 (Squeeze Page + Social Proof + Thank You)
- **Layout:** two-column-66-33 (основная) → three-column (доказательства) → single (thank you)
- **Особенности:**
  - Крючок-заголовок с обещанием результата
  - Буллеты с конкретными выгодами
  - Форма захвата с premium-оформлением
  - Социальные доказательства (цифры)
  - Thank You Page с видео и CTA на следующий шаг
- **Подходит для:** Все отрасли — самый простой способ начать

### Шаблон 2: Lead Magnet Funnel
- **Файл:** `docker/openfunnels/mcp/templates/lead-magnet-funnel.openfunnels.json`
- **Категория:** Lead
- **Секции:** 3 (Lead Magnet Page + Testimonials + Thank You)
- **Layout:** two-column (mockup + content) → three-column (отзывы) → single (thank you)
- **Особенности:**
  - Визуальный мокап продукта (ebook, руководство)
  - Строка зачёркнутой цены для ценности
  - Чёткие выгоды в формате «✓ пункт»
  - Три карточки-отзыва с аватарами
  - Thank You Page с бонусным оффером
- **Подходит для:** Авторы, ecommerce (купоны), B2B (whitepaper), ритейл

### Шаблон 3: Webinar Funnel
- **Файл:** `docker/openfunnels/mcp/templates/webinar-funnel.openfunnels.json`
- **Категория:** Event
- **Секции:** 4 (Registration + Details/Form + Confirmation + Replay/Offer)
- **Layout:** single → two-column → single → two-column
- **Особенности:**
  - Live-tag для urgency
  - Программа вебинара с нумерованными пунктами
  - Карточка спикера
  - Счётчик оставшихся мест
  - Replay с обратным отсчётом и оффером
  - Гарантия возврата
- **Подходит для:** Коучи, консультанты, B2B, MLM, информационные продукты

### Шаблон 4: Sales Letter Funnel
- **Файл:** `docker/openfunnels/mcp/templates/sales-letter-funnel.openfunnels.json`
- **Категория:** Buyer
- **Секции:** 6 (Headline + Story + Benefits + Order + OTO + Downsell)
- **Layout:** single → single → single → single → two-column → single
- **Особенности:**
  - Формула Star, Story, Solution
  - Длинное продающее письмо с эмоциональным storytelling
  - Буллеты с модулями продукта и бонусами
  - Зачётная таблица стоимости
  - Two-step order form
  - OTO (экспресс-курс) с «Да/Нет» кнопками
  - Downsell (рассрочка) на жёлтом фоне
- **Подходит для:** Инфопродукты, коучинг, ecommerce, B2B, MLM

### Шаблон 5: Application Funnel
- **Файл:** `docker/openfunnels/mcp/templates/application-funnel.openfunnels.json`
- **Категория:** Lead (high-ticket)
- **Секции:** 6 (Hero + Testimonial/Results + Who Is This For + Application Form + Thank You)
- **Layout:** single (hero) → two-column → two-column → two-column-66-33 → single
- **Особенности:**
  - Тёмный hero-секция для премиальности
  - Эксклюзивный тон («мы работаем не со всеми»)
  - Видео-кейс + статистика результатов
  - Раздел «для вас / не для вас» для квалификации
  - Предупреждение об ограниченных местах
  - 3-шаговый процесс (анкета → звонок → план)
  - Thank You с контактами и видео
- **Подходит для:** High-ticket коучинг, консалтинг, B2B, эксклюзивные услуги

## ЧАСТЬ 3: Рекомендации по использованию

### Какую воронку выбрать?

| Ваша цель | Рекомендация | Сложность |
|-----------|-------------|-----------|
| Собрать базу email | Squeeze Page или Lead Magnet | ⭐ |
| Продать дешёвый продукт | 2-Step Tripwire | ⭐⭐ |
| Продать дорогой продукт через видео | VSL Funnel | ⭐⭐ |
| Продать через длинное письмо | Sales Letter Funnel | ⭐⭐ |
| Провести вебинар | Webinar Funnel | ⭐⭐⭐ |
| Автоматизировать вебинар | AutoWebinar Funnel | ⭐⭐⭐ |
| Продать high-ticket услуги | Application Funnel | ⭐⭐⭐ |
| Запустить новый продукт | Product Launch Funnel | ⭐⭐⭐ |
| Создать.members-сайт | Membership Funnel | ⭐⭐⭐ |
| Удержать клиентов | Cancellation Funnel | ⭐ |

### Funnel Stacking (Стекинг воронок)

Ключевой концепт из книги: **первая воронка должна выходить в ноль** (break even). Цель — не прибыль, а клиенты. Затем:

1. **Фронтенд-воронка** (Squeeze/Lead Magnet/Tripwire) → Break even на рекламе
2. **Вторая воронка** (Webinar/Sales Letter) → Pure profit от уже купленных клиентов
3. **Третья воронка** (Application/High-ticket) → Максимальная прибыль

### Рекомендации по отраслям

| Отрасль | С чего начать | Затем |
|---------|---------------|-------|
| **Авторы/Коучи/Консультанты** | Lead Magnet (бесплатный ebook) | Application (high-ticket coaching) |
| **Профессиональные услуги** | Bridge Funnel (pre-sell) | Application (квалификация) |
| **Ритейл** | Coupon Funnel (Daily Deal) | Survey (персонализация) |
| **Ecommerce** | Storefront → Product Launch | Membership (программа лояльности) |
| **MLM/Аффилиаты** | Bridge Funnel | Webinar (обучение) |
| **B2B** | Application Funnel | Sales Letter (крупные сделки) |

### Технические рекомендации

1. **Начинайте просто** — не усложняйте воронку пока не освоите базовую
2. **Тестируйте заголовки** — A/B тестирование крючков
3. **Добавляйте социальные доказательства** — цифры, отзывы, кейсы
4. **Используйте scarcity** — таймеры, ограниченные места, дедлайны
5. **Follow-up обязателен** — автоматические email-последовательности после захвата лида
6. **Не бойтесь длинных продаж** — для дорогих продуктов длинное письмо работает лучше

## Структура шаблонов OpenFunnels

Каждый шаблон использует стандартный формат:

```json
{
  "kind": "openfunnels-template",
  "schemaVersion": 1,
  "metadata": { "name", "description", "category", "tags" },
  "funnel": {
    "content": { "sections": [...] },
    "settings": { "backgroundColor", "maxWidth" }
  }
}
```

**Layout-ы:**
- `single` — одна колонка (hero, sales letter, thank you)
- `two-column` — две равные колонки
- `two-column-66-33` — 66%/33% (copy + form)
- `three-column` — три колонки (features, testimonials)

**Блоки:**
- `text` — заголовки, описания, benefits
- `image` — hero-изображения, мокапы
- `form` — захват email, регистрация, заявка
- `button` — CTA кнопки
- `video` — VSL, demo, testimonials
- `testimonial` — отзывы
- `countdown` — обратный отсчёт
- `spacer` — разделители
