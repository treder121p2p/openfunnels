## Типы страниц (building blocks)

### Lead Pages
| Тип | Описание | OpenFunnels Layout |
|-----|----------|-------------------|
| Squeeze Page | Заголовок + форма захвата | two-column-66-33 (copy + form) |
| Reverse Squeeze | Видео/контент + форма | single (video) → two-column (cta + form) |
| Lead Magnet | Описание магнита + форма | single (benefits) → two-column (image + form) |
| Bridge Page | История + pre-sell + CTA | two-column (video + copy) |
| Survey Page | Опрос с вариантами | single (questions + progress bar) |
| Application | Квалификация + форма | two-column (benefits + application form) |

### Sales Pages
| Тип | Описание | OpenFunnels Layout |
|-----|----------|-------------------|
| Sales Letter | Длинное продающее письмо | single (long-form text + buy button) |

| VSL | Видео + порядок | single (video) → two-column (order) |
| Hero Page | Главный экран + CTA | single (hero section) |
| Product Launch | Серия预售 | 4 sections: tease → pre-launch → cart → close |

### Event Pages

## Маппинг на OpenFunnels

### Секции (Section Layout)
- `single` — одна колонка (hero, sales letter, thank you)
- `two-column` — две колонки (copy + form, video + benefits)
- `two-column-66-33` — 66%/33% (Squeeze Page: copy + form)
- `three-column` — три колонки (features, testimonials, benefits)

### Блоки (Block Types)
| Блок | Использование |
|------|--------------|
| `text` | Заголовки, описания, benefits |
| `image` | Hero-изображения, продукты, команды |
| `form` | Email захват, регистрация, заявка |
| `button` | CTA кнопки ("Buy Now", "Register", "Get Access") |
| `video` | VSL, demo, testimonials |
| `testimonial` | Социальное доказательство |
| `countdown` | Таймер дедлайна (для продаж) |
| `spacer` | Разделители секций |
| `countdown` | Обратный отсчёт |

### Настройки (Settings)
| Параметр | Рекомендация |
|----------|-------------|
| `backgroundColor` | Белый (#ffffff) для продаж, тёмный для hero |
| `padding` | 64-80px для hero, 32-48px для контента |
| `maxWidth` | 1200px для десктопа |
| `fontFamily` | Inter, sans-serif (по умолчанию) |
