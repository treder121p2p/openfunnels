## Маппинг на OpenFunnels

### Принцип
OpenFunnels работает с **отдельными страницами**. Каждая страница туннеля — отдельная воронка в сервисе.

**Как собирать туннель:**
1. Создаёте отдельные страницы (Squeeze, Thank You, Bridge и т.д.)
2. Каждая страница — отдельная воронка в OpenFunnels
3. Связываете через email-автоматизации (Automation Studio) или ссылки

### Блоки (Block Types)
| Блок | Использование |
|------|---------------|
| `text` | Заголовки, описания, benefits |
| `image` | Hero-изображения, продукты |
| `form` | Email захват, регистрация, заявка |
| `button` | CTA кнопки |
| `video` | VSL, demo |
| `testimonial` | Социальное доказательство |
| `countdown` | Таймер дедлайна |
| `spacer` | Разделители |
